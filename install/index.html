Install LUNA Base over USB

LUNA Base v0.9.0

No Python or esptool needed. Install LUNA Base on your board (ESP32) right from your PC's web browser. After this one time, firmware and LUNA Base updates come over Wi-Fi from LUNA Store.

What you need

  • Chrome or Edge on a PC (Windows, Mac or Linux). Phones, Safari and Firefox do not work
  • A USB cable that carries data (a charge-only cable shows no port)
  • An ESP32 board (such as the NS-4000 board, 4MB)

How to install

  1. Connect the board to your PC with USB
  2. Press "Install" below, choose the board's port in the list and press "Connect" (names such as COM3, USB Serial, CP210x or CH340)
  3. Press "Install LUNA Base", then "Install". It takes 2 to 3 minutes. Do not unplug the USB until it finishes
  4. When "Installation complete!" appears, you are done. If the board does not start by itself, press EN (reset) or unplug and plug in the USB
  5. Connect your phone or PC to the Wi-Fi whose name starts with "LUNA-BASE-" and open http://192.168.4.1 in the browser. Choose and install your firmware from LUNA Store

This browser cannot install. Open this page in Chrome or Edge on a PC.

This page must be opened over https.

Your settings are kept
Nothing on the board is erased, so your home Wi-Fi, PIN and mount settings stay. The firmware you had is replaced, so install it again from LUNA Store in LUNA Base.

If it does not work

  • No port in the list: try another cable. If there is still none, install the driver for the USB chip on your board (look at the chip next to the USB connector): CP210x (Silicon Labs), CH340 (WCH)
  • It does not connect or start writing (such as "Failed to initialize"): hold BOOT on the board, press and release EN, release BOOT, then press "Install" again
  • It stopped part way: just install again. Stopping while writing does not damage the board
  • Another app using the port (such as the Arduino IDE serial monitor) blocks the connection. Close it and try again
